Train Wi-Fi blocked? Use the bridge
  1. Copy the bridge code.
  2. Open https://www.ombord.info/api/jsonp/position/ in a new tab.
  3. Press F12 → Console, type allow pasting if asked, paste the code and press Enter.
  4. A new RailVerse tab opens and receives the train's GPS. Keep the portal tab open.

Speed and GPS come from the train's onboard Wi-Fi portal and only work when connected to it. The Trafikverket key adds real stops, delays and track numbers. The key is kept on this device only.
